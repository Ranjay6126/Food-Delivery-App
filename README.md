# Food-Delivery-App
A modern, responsive Food Delivery Web App built using HTML, CSS, and JavaScript. This project simulates an online food ordering platform where users can browse restaurants, view food items, add them to the cart, and place an order — all with smooth UI interactions and clean design.

🍔 Food Delivery App

A modern, responsive food delivery web application built using HTML, CSS, and JavaScript. This project simulates a real-world online food ordering platform where users can browse restaurants, explore food items, manage their cart, and place orders with smooth UI interactions.

🚀 Features

Browse restaurants and food items

Add and remove items from the cart

Real-time cart updates using JavaScript

Dynamic price calculation

Responsive design for desktop and mobile

Clean and user-friendly UI

🛠 Tech Stack

HTML for structure

CSS for styling and responsiveness

JavaScript for application logic and interactivity

🎯 Purpose

This project was built to practice front-end development concepts, DOM manipulation, and JavaScript-based functionality while creating a realistic food delivery experience.

📌 Future Improvements

User authentication

Order history

Backend integration

Payment gateway simulations
